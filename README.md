# AternosServerOpener

AternosServerOpener is a Minecraft mod for Fabric loader version 1.20.4 that allows you to open Aternos servers directly from within the game. This mod provides an in-game interface to manage and open your Aternos servers, making it easier to access your servers without leaving Minecraft.

## Installation

1. Install Fabric loader version 1.20.4 for Minecraft.
2. Download the AternosServerOpener mod jar.
3. Place the jar file in the `mods` folder of your Minecraft installation.

## Usage

1. Launch Minecraft with the Fabric loader.
2. Open the mod's GUI by using the provided in-game interface.
3. Enter your Aternos server details to open the server directly from within Minecraft.
